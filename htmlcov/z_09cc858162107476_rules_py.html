473def _easter(year: int) -> date: 

474 """Return Gregorian Easter Sunday using the Meeus/Jones/Butcher algorithm. 

475 

476 Args: 

477 year (int): Gregorian calendar year. 

478 

479 Returns: 

480 date: Easter Sunday in the given year. 

481 """ 

482 a = year % 19 

483 b, c = divmod(year, 100) 

484 d, e = divmod(b, 4) 

485 f = (b + 8) // 25 

486 g = (b - f + 1) // 3 

487 h = (19 * a + b - d - g + 15) % 30 

488 i, k = divmod(c, 4) 

489 weekday_correction = (32 + 2 * e + 2 * i - h - k) % 7 

490 m = (a + 11 * h + 22 * weekday_correction) // 451 

491 month, day = divmod(h + weekday_correction - 7 * m + 114, 31) 

492 return date(year, month, day + 1)
